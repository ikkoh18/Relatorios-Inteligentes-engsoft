Como outros módulos se integram

Use os endpoints abaixo para enviar dados e consumir relatórios.

Módulo 2 → envia arquivos aqui:

POST /reports/receive-file
Content-Type: multipart/form-data

file: <arquivo>
projeto_id: "nome-do-projeto"

# Ou via JSON:
POST /reports/ingest
{
  "projeto_id": "nome-do-projeto",
  "conteudo": "texto dos arquivos",
  "template": "sprint_review"
}

Módulos 4 e 5 → consomem relatórios aqui:

GET /reports/list
→ lista todos os relatórios prontos

GET /reports/get/{id}
→ retorna o conteúdo Markdown de um relatório específico

Documentação interativa:

Abrir /docs — FastAPI Swagger UI →

Pasta de outputs

Todos os relatórios gerados são salvos automaticamente em:

app/storage/outputs/
├── projeto_sprint_review_20260413_143022.md
├── projeto_sprint_review_20260413_143022.json
└── ...

Cada relatório tem um .md (conteúdo) e um .json (metadados com projeto_id, template, data e arquivos de origem).
